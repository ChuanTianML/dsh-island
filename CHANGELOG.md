# Changelog

All notable changes to DSH Island are documented here.

## 0.1.0 - 2026-08-14

- Add a native, always-on-top macOS capsule with collapsed and expanded session views.
- Fold the current DSH `session.list`, Host WebSocket, and mux WebSocket into one tested status engine.
- Show attention, failure, running, recently completed, idle, offline, Todo progress, activity, jobs, and subagent families.
- Add endpoint trust controls, privacy redaction, position persistence, login launch, menu-bar recovery, and deterministic demo mode.
- Ship a universal ad-hoc-signed application bundle with CI and tag-driven GitHub Releases.
